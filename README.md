## 🇪🇸 Español

### Qué es

Juego de ta-te-ti en consola, escrito para practicar C++: el jugador (`X`) juega contra la computadora (`O`), que elige casilleros al azar.

### Conceptos practicados

- Arrays y punteros (`char *espacios`).
- Funciones separadas para dibujar el tablero, turnos, ganador y empate.
- Números aleatorios con `<ctime>`.

### Compilar y jugar

```bash
g++ tic-tac-toe.cpp -o tic-tac-toe
./tic-tac-toe
```

---

## 🇬🇧 English

### What it is

Console tic-tac-toe written to practise C++: the player (`X`) plays against the computer (`O`), which picks random squares.

### Concepts

- Arrays and pointers, one function per responsibility (board, turns, win/draw checks), random numbers with `<ctime>`.

### Build & play

```bash
g++ tic-tac-toe.cpp -o tic-tac-toe
./tic-tac-toe
```
